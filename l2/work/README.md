# L2 Work Tracking

Level-owned plans belong under `l2/work/plans/<kind>/`; closed plans move to `closed/`. New plans omit `Stage` metadata
and follow the root ADR Impact policy. Generic planning/finalization skills remain at the monorepo root. The completed
shared split is recorded under
[work/plans/refactors/closed/2026-10-10-shared-l1-l2-canonical-compiler-split-noref.md](../../work/plans/refactors/closed/2026-10-10-shared-l1-l2-canonical-compiler-split-noref.md)
and linked from [l2/docs/roadmap.md](../docs/roadmap.md).

New plans use `Severity` for Bug Fix work and `Priority` for Feature, Refactor, and Tooling work. Use exactly one field;
see [work/README.md](../../work/README.md#plan-priority-and-severity) for definitions and rating criteria.
