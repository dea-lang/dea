## Summary

Prepared L0 2.2.0 on `wip/googlielmo`, comparing its implemented changes with `l0-v2.1.1`. The minor version recognizes
the substantial independent stage references and offline distribution documentation improvements. The compiler changes
repair existing behavior; they do not add L0 syntax, compiler CLI options, standard-library APIs, or public C
interfaces.

The preparation includes final current-release wording for the tagged tree and prescriptive release sequencing for all
language levels. Metadata, canonical notes, and current-release documentation must precede the tag; package metadata
retains `X.Y.Z.dev0`. Level-specific validation, artifact inventories, and publication requirements remain separately
owned. The shared workflow guide orders its level-specific working sections as L0, L1, then L2.

This plan covers local release preparation only. The project maintainer reported green CI on `main` before preparation;
that report does not establish validation of the new release metadata or the eventual release target.

## Handoff and Publication Boundary

This plan ends at the local preparation commit on `wip/googlielmo`. Promotion and the actual release from `main` are
deferred to separately authorized follow-up work. The exact final release notes still require project maintainer review.
No tags, pushes, release edits, workflow dispatches, deployments, or cross-repository writes are part of preparation.
The eventual `l0-v2.2.0` target on `main` must pass required validation; release artifacts must be rebuilt from that
exact target. A later authorized tag push to `https://github.com/dea-lang/dea` can publish release assets, deploy Pages,
and dispatch a downstream blog update under the existing manual authorization gates.
