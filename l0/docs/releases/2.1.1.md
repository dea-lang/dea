# Dea/L0 2.1.1

Dea/L0 2.1.1 fixes ARC cleanup for temporary values used in comparisons and makes AddressSanitizer test validation more
reliable across configured toolchains.

## Runtime correctness

- Fix ARC cleanup for temporary `string` and optional values in comparisons in both compiler stages, preventing leaks
  and incorrect releases.
- Preserve ownership through casts and optional extraction, clean up temporary aggregates used for field access, and
  correctly scope temporary cleanup in `for`-loop update expressions.

## Validation

- Harden AddressSanitizer test validation with bounded compile and run deadlines, preservation of the configured
  compiler, and a non-PIE compatibility fallback for affected host toolchains.

## Compatibility

- No changes to L0 syntax, CLI options, public C interfaces, standard-library APIs, or diagnostic codes.

See the
[full comparison between l0-v2.1.0 and l0-v2.1.1](https://github.com/dea-lang/dea/compare/l0-v2.1.0...l0-v2.1.1).

Release archives and generated API documentation accompany the published release. Use `SHA256SUMS` to verify downloaded
assets.
